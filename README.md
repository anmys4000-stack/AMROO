## حماية البيانات الشخصية
البيانات حقيقية لطلاب ومعلمين، لذلك نطبّق من البداية:
- **تقليل البيانات:** نجمع فقط ما يلزم للعمل المدرسي.
- **عزل المدارس:** كل سجل مرتبط بـ `schoolId`، ولا يُعرض إلا لمستخدمي المدرسة نفسها.
- **كلمات المرور:** تُخزَّن مُجزّأة فقط، ولا تُخزَّن كنص واضح أبدًا.
- **الأسرار:** لا تُرفع ملفات `.env` ولا مفاتيح الوصول إلى المستودع.
- **سجل التدقيق:** تُسجَّل العمليات الحساسة لمراجعتها لاحقًا.
- **الصلاحيات:** كل دور يرى ما يخص وظيفته فقط.
- **الاستضافة:** Render مع اتصال مشفّر (SSL) بقاعدة البيانات.

> ملاحظة: مراجعة الامتثال الكامل لنظام حماية البيانات الشخصية السعودي (PDPL) تتطلب مراجعة قانونية من مختص، والكود وحده لا يكفي.
